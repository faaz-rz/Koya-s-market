# App Store reviewer access

Koya Stores supports customer sign-in using a six-digit email code. Before submission,
provide full access for App Review through a working demo account or an
appropriate demo mode. Confirm access from a fresh install using only what
you supply in App Store Connect. The reviewer path for the email-code-only
build remains to be verified.

Reviewers should be able to browse the catalogue, use pickup and a serviceable
test delivery address, and open Privacy policy and Delete account. Use ordinary
customer access and keep live staff credentials private.

[Apple App Review information](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information)
